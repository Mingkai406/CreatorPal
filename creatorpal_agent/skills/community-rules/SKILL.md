Call read_community_rules for communities already returned by search_communities. Cite rules
evidence separately from topical evidence. A positive sentiment score is not permission to post.
Report the source's collection date. If rules are unavailable, explain the gap rather than
inventing a policy. This tool reads supplied snapshots; it does not guarantee current rules.
